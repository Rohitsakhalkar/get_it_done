# Get It Done

Get It Done is a freelancing and task-based platform designed to connect people who need work done with people who have the skills to complete it. The platform focuses on smaller tasks and local opportunities, making it easier for students and individuals to find work and gain practical experience.

The project combines task management with social features to create a platform where users can discover opportunities, connect with others, and collaborate.

## Features

- Create and manage tasks
- Assign tasks to users
- Track task progress and status
- Task cancellation with mutual agreement
- Location-based task discovery
- Social posts and user connections
- Direct messaging
- Task-related communication
- User reporting and moderation

## Task Lifecycle

Tasks follow a structured lifecycle:

`Open → Assigned → In Progress → Completed`

Tasks can also be cancelled, with cancellation rules designed to protect both parties involved.

The backend follows a modular structure separating API routes, database models, schemas, and database configuration.

This separation helps maintain the codebase as new features and functionality are introduced.

## Project Status

Currently under development.

Development is focused on building the backend foundation and implementing the core task management functionality. Additional features will be introduced incrementally.

## Motivation

The idea behind Get It Done is to make smaller work opportunities more accessible.

Many people have skills they can offer, while others need help with tasks but lack an easy way to find someone. Get It Done aims to bridge that gap through a simple platform focused on tasks, people, and opportunities.
